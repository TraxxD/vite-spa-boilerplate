# Vite SPA Boilerplate

A minimal boilerplate for building Single Page Applications (SPA) with [Vite](https://vitejs.dev/).

## Features

- Fast development server with Hot Module Replacement (HMR)
- Optimized production builds
- Minimal configuration out of the box

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/TraxxD/vite-spa-boilerplate.git
cd vite-spa-boilerplate

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
